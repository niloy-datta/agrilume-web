# AgriLume — Earth Intelligence for Agriculture
## NASA Space Apps Challenge 2026 • Phase 1 Specification Document

=============================================================================
PRODUCT & MISSION OVERVIEW
=============================================================================
- Name: AgriLume
- Core Narrative: SPACE → EARTH → FIELD → FARMER → ACTION
- Core Message: NASA/Earth data → scientific evidence → farmer decision
- Primary Tagline: FROM SPACE. TO SOIL. TO ACTION.
- Supporting Statement: Earth intelligence for better farming decisions.
- Aesthetic Direction: NASA Mission Control × Apple product storytelling × premium climate/agri-tech

=============================================================================
PHASE 1 IMPLEMENTED SCOPE
=============================================================================
1. Global Visual & Design System:
   - Root space atmosphere palette (#050A12)
   - Atmospheric Cyan (#36BFFA) and Agri Green (#59D98E) accents
   - Warm Earth (#D7A86E) transitional undertones
   - Editorial typography via Space Grotesk & Inter
   - Telemetry grid background & restrained focal glow effects

2. Root Layout & Metadata:
   - Next.js 16 App Router architecture
   - Accessible metadata, viewport configurations, and dark theme defaults

3. Premium Responsive Navbar:
   - Fixed positioning with dynamic blur and border activation upon scroll
   - Brand glyph with active orbital beacon
   - Main navigation anchors (Mission, Science, Impact)
   - Primary "Launch Mission →" call-to-action
   - Responsive mobile navigation drawer with scroll lock

4. Full-Screen Cinematic Hero:
   - 100svh minimum height
   - Colossal responsive headline:
     FROM SPACE.
     TO SOIL.
     TO ACTION.
   - Restrained scientific eyebrow: "EARTH INTELLIGENCE FOR AGRICULTURE"
   - Scientific supporting copy
   - Dual action CTAs with glow effects
   - Verified data trust line: "Evidence before advice • Earth data • Farmer action"

5. Hero Visual (Earth Orbital System):
   - Multi-layer vector planetary sphere with atmospheric limb glow
   - Tilted elliptical orbital trajectory
   - Contextual satellite marker (Earth Observation Layer / Orbital & Climate Context)
   - Demonstration field beacon with concentric radar pulses (Rajshahi, Bangladesh Demo Context)
   - Desktop mouse parallax depth tracking with spring physics
   - Prefers-reduced-motion safety fallback

6. Initial Scroll Transition Section:
   - Visual transition warming from deep space black to #0B1220
   - Conceptual architecture preview banner
   - 3-step pipeline preview (Earth Data → Scientific Analysis → Farmer Decision)
