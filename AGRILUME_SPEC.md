# AgriLume — Earth Intelligence for Agriculture
## NASA Space Apps Challenge 2026 • Phase 1 & 2 Specification Document

=============================================================================
PRODUCT & MISSION OVERVIEW
=============================================================================
- Name: AgriLume
- Core Narrative: SPACE → EARTH → FIELD → UNCERTAINTY → DECISION → ACTION
- Core Message: NASA/Earth data → scientific evidence → farmer decision
- Primary Tagline: FROM SPACE. TO SOIL. TO ACTION.
- Supporting Statement: Earth intelligence for better farming decisions.
- Aesthetic Direction: NASA Mission Control × Apple product storytelling × premium climate/agri-tech

=============================================================================
PHASE 1 IMPLEMENTED SCOPE
=============================================================================
1. Global Visual & Design System (#050A12 Space, #0B1220 Surface, #36BFFA Cyan, #59D98E Green, #D7A86E Warm Earth)
2. Root Layout & Next.js 16 App Router Metadata
3. Premium Responsive Navbar (Fixed, blur on scroll, mobile drawer)
4. Full-Screen Cinematic Hero ("FROM SPACE. TO SOIL. TO ACTION.")
5. Hero Visual (Earth Orbital Vector System with non-live demo context)
6. Initial Scroll Transition Section (Architecture preview: Earth Data → Analysis → Decision)

=============================================================================
PHASE 2 IMPLEMENTED SCOPE (HUMAN PROBLEM & SIGNATURE COMPARISON)
=============================================================================
1. Farmer Problem Narrative Section (Anchor: id="mission"):
   - Eyebrow: "THE DECISION ON THE GROUND"
   - Primary Headline: "A FARMER SEES THE FIELD. BUT NOT EVERYTHING SHAPING IT."
   - Hero Question: “Should I plant today — or wait?”
   - 3 Uncertainty Cues: Weather, Timing, Evidence
   - Abstract field composition with horizon, soil furrows, and Rajshahi vantage marker

2. Signature Split-Screen Comparison Section (Anchor: id="science"):
   - Headline: "SAME FIELD. MORE CONTEXT."
   - Core Visual Equation: LOCAL KNOWLEDGE + EARTH INTELLIGENCE → BETTER-INFORMED DECISIONS
   - What the Farmer Sees (Natural ground observations & respectful quote)
   - What AgriLume Sees (Spectral raster grid, soil moisture context, thermal trends, limitations)
   - Desktop: Draggable interactive vertical reveal divider (Keyboard operable, ARIA slider)
   - Mobile: Two-state view toggle ([FARMER VIEW] [AGRILUME VIEW]) with smooth cross-fade
   - Scientific Credibility: Zero fake numbers or fabricated measurements

=============================================================================
STRICT PHASE BOUNDARIES (NOT INCLUDED IN PHASE 1 & 2)
=============================================================================
The following modules are deliberately excluded until Phase 3:
- Live NASA API integrations / NASA POWER
- Interactive map tile engines / satellite imagery picker
- Farmer agronomic dashboard & live charts
- Authentication / Database backend
- Team profiles / pricing / marketplace
